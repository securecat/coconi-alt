# アクセシビリティ

最終更新：2026-11-07

## 優先事項と目標

ここにaltは、Webページ上の画像が持つalt属性やaria-labelの内容を、画面に文字として表示するChrome拡張です。スクリーンリーダー利用者が普段「耳で見ている」内容を、晴眼者が目で確認できるようにすることで、altテキストの有無や内容を手早くチェックできるようにすることを目的としています。つまりここにalt自体が、ウェブ制作やコンテンツ作成に関わる人たちのアクセシビリティチェックを支援する道具です。

この文書が対象とするのは、次のとおりです。

- 拡張機能そのもののUI（ポップアップと設定〈オプション〉ページ）
- ページ内の画像を置き換えて表示する機能自体（パネルモード・テキストモード）

UIは WCAG 2.2 のレベル AA を目標とし、これを上限ではなく下限と考えています。AAより厳しい独自の基準もあります（[貢献者への期待](#貢献者への期待)を参照）。第三者による試験は受けていないため、これは目標であり、適合を表明するものではありません。

## 画像の置き換え表示について

- ここにaltが表示するのは、ページが持つalt属性やaria-labelの内容そのものです。「AIによる推測」機能を除き、ここにalt自身が文章を作ることはありません
- 「AIによる推測」は、alt属性を持たない画像を対象にした実験的機能です。Chrome内蔵AI（Gemini Nano）が画像単体から生成した文章を、「AIによる推測：」という接頭辞つきで表示します。生成される文章の正確性は保証されません
- パネルモードの置き換え要素はボタンとして実装しており、クリックだけでなくEnterキー・スペースキーでも展開・折りたたみを操作できます
- 元のページ自体のアクセシビリティ（画像にalt属性が無い、内容が不適切である等）は、ここにaltの対象外です。ここにaltは、それを可視化するだけです

## 対応している環境

- ブラウザ：Google Chrome、Microsoft Edge（Chromium版）。ただし「AIによる推測」機能はGoogle Chrome内蔵のAI（Gemini Nano）を使うため、Google Chromeでのみ利用できます
- スクリーンリーダー：Windows の NVDA で読み上げを確認済みです。ほかのスクリーンリーダーはまだ試していません
- すべての機能を、キーボードだけで操作できます

## 既知の制限

- `chrome://` ページやChromeウェブストアなど、拡張機能が動作できない特権ページでは機能しません（Chrome拡張機能全般の制約です）
- 元画像がflexboxの `justify-content: center` や `transform` によるセンタリングなどで配置されている場合、置き換え要素がそれに追従しないことがあります（`display: block` と `margin: auto` の組み合わせによるセンタリングには対応しています）
- 「AIによる推測」機能は対応ハードウェア（十分な空き容量・GPU）が必要で、環境によっては利用できません。利用できない場合はsrcのフルパス表示にフォールバックします

## アクセシビリティの問題を報告する

問題は [GitHub Issues](https://github.com/securecat/coconi-alt/issues) で報告してください。日本語でも英語でも構いません。

次のことを書いてもらえると助かりますが、どれも任意です。

- 何をしようとしていたか
- 使っていた画面や機能
- 何が起きたか、どうなると思っていたか
- OS、ブラウザのバージョン、ここにalt のバージョン
- 使っている支援技術（スクリーンリーダーなど）

障害の有無や内容を書く必要はありません。スクリーンショットや録画も必須ではありません。

## 貢献者への期待

ここに挙げることは、人間の貢献者にもコーディングエージェントにも、同じように求めます。

UIを変更するときは、次を守ってください。

- フォームにはネイティブの要素（`<input>`・`<select>`・`<textarea>`）を使う。`<div>` や `<span>` をボタンの代わりにしない。画面内の操作には `<button>`、ページの移動には `<a>` を使う
- `disabled` 属性を使わない
- フォーカスインジケーターを消さない（`outline: none` を使わない）
- リンクの下線を消さない
- テキストのコントラスト比は、本文で 7:1 以上、補足的なテキストで 4.5:1 以上にする。ライトテーマとダークテーマのそれぞれで満たす
- 境界線やアイコンなど、テキスト以外の要素も、隣り合う色に対して 3:1 以上にする
- コントラストが必要な要素に `opacity` を使わない
- 文字サイズは、日本語で 16px 以上、英語で 14px 以上にする
- `font-family` は `sans-serif` にする（`system-ui` は使わない）
- ステータスメッセージを自動で消さない
- 自動スクロールなど、ひとりでに動くものを作らない

変更したあとは、キーボードだけですべて操作できること、スクリーンリーダーで内容が正しく読み上げられることを確認してください。

`content.js` で画像・`role="img"` 要素を置き換える要素を追加・変更するときは、元要素の配置（`display` や `margin` によるセンタリング等）を置き換え要素にも引き継ぎ、ウィンドウのリサイズ時にも再計算されるようにしてください。また、テキストを選択可能にした要素にクリックハンドラを付ける場合は、ドラッグによるテキスト選択時にクリックが誤発火しないよう、選択状態を確認してから処理してください。
